# Browser Symptom Pattern Explorer

`S1-2026-07-29` is a feasibility starter for the Browser Symptom Pattern
Explorer. It is a bounded, nonclinical research demonstration, not a medical
device, diagnostic system, or triage tool.

Never enter private patient information. Use only fictional or published
educational symptom descriptions.

The sentence-embedding model runs in each visitor's browser. The static hosts
serve the HTML, CSS, JavaScript, and model-loading instructions; they do not
run an application backend, and the app requires no inference API or API key.

The code began as a mentor-supplied, AI-assisted reference implementation.
That implementation is distinct from Chengry's later account-owned
deployments, recorded observations, project decisions, explanations, and sole
authorship of any accompanying paper.
